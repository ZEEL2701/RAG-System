The Agentic RAG with Locally Running LLaMA3 and Google Search API for SOL-BI is a retrieval-augmented AI assistant that integrates with Sol-BI to provide contextual, real-time responses. It utilizes LLaMA3 as a local language model for document retrieval and response generation while leveraging Google Search API as a fallback for broader queries. The system includes self-correcting AI mechanisms, hallucination detection, and response grading, ensuring accuracy and reliability.
